# MCP TypeScript SDK vs mcp-use

| | [MCP TypeScript SDK](../fichas/mcp-typescript-sdk.md) | [mcp-use](../fichas/mcp-use.md) |
|---|---|---|
| Qué hace | SDK oficial de TypeScript para crear servidores y clientes del Model Context Protocol. | Framework fullstack para construir MCP Apps y MCP Servers en TypeScript o Python, con utilidades para pasar de un prototipo local a una app desplegable. |
| ⭐ Estrellas | 13.7k | 10.9k |
| Elígelo si… | creas servidores MCP en TypeScript | construyes un servidor MCP propio y quieres productividad |
| Evítalo si… | trabajas en Python; mira `fastmcp` | solo buscas usar uno ya hecho (awesome-mcp-servers) o necesitas control a nivel spec |
| Ejecución | 🏠 local | 🔀 híbrido |
| Setup | 🟢 fácil | 🟡 medio |
| Licencia | Otra (ver repo) | MIT |
| Instalación | `npm install @modelcontextprotocol/sdk` | `npm install mcp-use` |

## Regla práctica

- Elige **MCP TypeScript SDK** si creas servidores MCP en TypeScript.
- Elige **mcp-use** si construyes un servidor MCP propio y quieres productividad.
- Usa los dos solo si el proyecto necesita explícitamente ambas capacidades.
