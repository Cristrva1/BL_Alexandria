## Regla práctica

- Elige **MCP TypeScript SDK** si Tu objetivo encaja con estos ejemplos: Construir un servidor MCP en TypeScript; Crear un cliente que enumere herramientas.
- Elige **mcp-use** si Tu objetivo encaja con estos ejemplos: Construir una herramienta con interfaz embebida; Desplegar un servidor MCP para una app propia.
- Usa los dos solo si el proyecto necesita explícitamente ambas capacidades.
