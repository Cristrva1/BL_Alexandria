## Regla práctica

- Elige **assistant-ui** si Tu objetivo encaja con estos ejemplos: Construir un chat para una app; Añadir herramientas y adjuntos a una conversación.
- Elige **CopilotKit** si Tu objetivo encaja con estos ejemplos: Añadir asistencia contextual a una app; Mostrar componentes generados a partir de respuestas.
- Usa los dos solo si el proyecto necesita explícitamente ambas capacidades.
