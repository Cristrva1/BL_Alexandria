# Material UI vs ui

| | [Material UI](../fichas/mui.md) | [ui](../fichas/ui.md) |
|---|---|---|
| Qué hace | Librería de componentes React completa que implementa Material Design de Google. | Colección de componentes copy-paste para React/Tailwind (shadcn/ui) que vives dentro de tu repo en lugar de instalar como dependencia cerrada. |
| ⭐ Estrellas | 99.3k | 128k |
| Elígelo si… | quieres una librería React completa y probada | quieres ser dueño del código de UI |
| Evítalo si… | prefieres copiar componentes y estilarlos con Tailwind; mira `ui` | prefieres una lib "llave en mano" con updates automáticos (heroui) |
| Ejecución | 🏠 local | 🏠 local |
| Setup | 🟢 fácil | 🟢 fácil |
| Licencia | MIT | MIT |
| Instalación | `npm i @mui/material @emotion/react @emotion/styled` | `npx shadcn@latest init` |

## Regla práctica

- Elige **Material UI** si quieres una librería React completa y probada.
- Elige **ui** si quieres ser dueño del código de UI.
- Usa los dos solo si el proyecto necesita explícitamente ambas capacidades.
