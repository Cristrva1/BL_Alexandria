# AudioCraft vs YuE2

| | [AudioCraft](../fichas/audiocraft.md) | [YuE2](../fichas/yue.md) |
|---|---|---|
| Qué hace | Librería PyTorch de Meta para generar música y efectos de sonido desde texto, con MusicGen, AudioGen y el códec EnCodec. | Modelo abierto de generación de canciones completas (voz y acompañamiento) a partir de letra y estilo, con partitura editable, covers y una skill para agentes. |
| ⭐ Estrellas | 23.9k | 13.5k |
| Elígelo si… | Tu objetivo encaja con estos ejemplos: Explorar generación de música; Estudiar sonidos a partir de texto | Tu objetivo encaja con estos ejemplos: generar una maqueta de canción con letra propia para un proyecto personal o académico; editar la armonía de una canción generada manteniendo la melodía |
| Evítalo si… | Necesitas funciones o garantías fuera del alcance descrito; revisa los límites y requisitos antes de elegirlo | no tienes el hardware o no aceptas la licencia de los pesos |
| Ejecución | 🏠 local | 🏠 local |
| API de IA | Sin clave propia de API de IA en la ruta básica | Sin clave propia de API de IA en la ruta básica |
| Coste | El coste depende del proveedor o la ruta | Sin pago a un modelo en la ruta básica |
| Modelos locales | Modelos locales documentados | Modelos locales documentados |
| Setup | 🟡 medio | hard |
| Licencia | MIT | Apache-2.0 |
| Instalación | `python -m pip install -U audiocraft` | `git clone https://github.com/multimodal-art-projection/YuE.git` |

## Regla práctica

- Elige **AudioCraft** si Tu objetivo encaja con estos ejemplos: Explorar generación de música; Estudiar sonidos a partir de texto.
- Elige **YuE2** si Tu objetivo encaja con estos ejemplos: generar una maqueta de canción con letra propia para un proyecto personal o académico; editar la armonía de una canción generada manteniendo la melodía.
- Usa los dos solo si el proyecto necesita explícitamente ambas capacidades.
