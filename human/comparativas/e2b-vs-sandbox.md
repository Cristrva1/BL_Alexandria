## Regla práctica

- Elige **E2B** si Tu objetivo encaja con estos ejemplos: Ejecutar código aislado de una app; Preparar un entorno temporal para un agente.
- Elige **sandbox** si Tu objetivo encaja con estos ejemplos: Probar herramientas de un agente en un contenedor; Consultar una interfaz de navegador aislada.
- Usa los dos solo si el proyecto necesita explícitamente ambas capacidades.
