## Regla práctica

- Elige **GitNexus** si Tu objetivo encaja con estos ejemplos: Entender una base de código nueva; Inspeccionar el alcance de una refactorización.
- Elige **Repomix** si Tu objetivo encaja con estos ejemplos: Preparar contexto de código para una consulta; Compartir una muestra reproducible de un proyecto.
- Usa los dos solo si el proyecto necesita explícitamente ambas capacidades.
