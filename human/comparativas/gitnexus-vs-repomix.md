# GitNexus vs Repomix

| | [GitNexus](../fichas/gitnexus.md) | [Repomix](../fichas/repomix.md) |
|---|---|---|
| Qué hace | Herramienta visual para explorar y entender repositorios Git, mostrando estructura y relaciones para acelerar el onboarding en una base de código nueva. | Empaqueta un repositorio entero en un solo archivo listo para pasarlo a un LLM. |
| ⭐ Estrellas | 48.4k | 29.2k |
| Elígelo si… | quieres entender un repo puntual de forma visual | quieres dar tu repo completo a un LLM |
| Evítalo si… | necesitas indexar muchos repos a escala (codegraph) o no quieres front web | el repo es enorme; mira `codebase-memory-mcp` o `serena` |
| Ejecución | 🔀 híbrido | 🏠 local |
| Setup | 🟢 fácil | 🟢 fácil |
| Licencia | Otra (ver repo) | MIT |
| Instalación | `git clone https://github.com/abhigyanpatwari/GitNexus` | `npx repomix` |

## Regla práctica

- Elige **GitNexus** si quieres entender un repo puntual de forma visual.
- Elige **Repomix** si quieres dar tu repo completo a un LLM.
- Usa los dos solo si el proyecto necesita explícitamente ambas capacidades.
