# D2 vs Mermaid

| | [D2](../fichas/d2.md) | [Mermaid](../fichas/mermaid.md) |
|---|---|---|
| Qué hace | Lenguaje declarativo de diagramas que convierte texto en diagramas SVG, PNG, PDF o PPTX, con temas, modo boceto y tres motores de layout incluidos. | Genera diagramas de flujo, secuencia, Gantt y más a partir de texto similar a Markdown. |

| Coste | Sin pago a un modelo en la ruta básica | Sin pago a un modelo en la ruta básica |
| Modelos locales | La función básica no necesita un modelo | La función básica no necesita un modelo |
| Setup | 🟢 fácil | 🟢 fácil |
| Licencia | MPL-2.0 | MIT |
| Instalación | Sigue la instalación y el ejemplo mínimo en https://github.com/d2lang/d2/blob/master/RE… | `npm install mermaid` |

## Regla práctica

- Elige **D2** si Tu objetivo encaja con estos ejemplos: mantener diagramas de arquitectura como texto versionado junto al código; generar diagramas desde scripts o documentación técnica.
- Elige **Mermaid** si Tu objetivo encaja con estos ejemplos: Documentar un proceso; Preparar un diagrama de secuencia.
- Usa los dos solo si el proyecto necesita explícitamente ambas capacidades.
