# Botpress vs Typebot

| | [Botpress](../fichas/botpress.md) | [Typebot](../fichas/typebot.md) |
|---|---|---|
| Qué hace | Plataforma para construir y desplegar agentes conversacionales con LLM en web, WhatsApp y más. | Constructor visual de chatbots conversacionales, auto-hospedable, para web, WhatsApp y más. |
| ⭐ Estrellas | 15k | 10.6k |
| Elígelo si… | quieres un agente conversacional multicanal con poco código | quieres un chatbot guiado sin programar, con buena UX |
| Evítalo si… | necesitas todo self-host y sin nube; mira `rasa` o `typebot` | necesitas un agente abierto con razonamiento libre; mira `botpress` |
| Ejecución | 🔀 híbrido | 🏠 local |
| Setup | 🟡 medio | 🟡 medio |
| Licencia | MIT | Otra (ver repo) |
| Instalación | `npm i -g @botpress/cli` | Self-host con Docker Compose siguiendo la guía del repo (requiere PostgreSQL y SMTP), o… |

## Regla práctica

- Elige **Botpress** si quieres un agente conversacional multicanal con poco código.
- Elige **Typebot** si quieres un chatbot guiado sin programar, con buena UX.
- Usa los dos solo si el proyecto necesita explícitamente ambas capacidades.
