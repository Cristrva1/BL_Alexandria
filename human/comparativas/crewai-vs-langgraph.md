# crewAI vs LangGraph

| | [crewAI](../fichas/crewai.md) | [LangGraph](../fichas/langgraph.md) |
|---|---|---|
| Qué hace | Framework para orquestar "crews" de agentes con roles y tareas. | Framework de LangChain para agentes con estado como grafos, con persistencia, human-in-the-loop y streaming. |
| ⭐ Estrellas | 60.7k | 44.7k |
| Elígelo si… | quieres velocidad y un modelo mental simple de "equipo" | necesitas agentes con estado, control fino y persistencia |
| Evítalo si… | necesitas control de bajo nivel o orquestación muy custom | quieres algo mínimo para un agente simple; mira `smolagents` |
| Ejecución | ☁️ cloud/API | 🔀 híbrido |
| Setup | 🟢 fácil | 🟡 medio |
| Licencia | MIT | MIT |
| Instalación | `pip install crewai` | `pip install -U langgraph` |

## Regla práctica

- Elige **crewAI** si quieres velocidad y un modelo mental simple de "equipo".
- Elige **LangGraph** si necesitas agentes con estado, control fino y persistencia.
- Usa los dos solo si el proyecto necesita explícitamente ambas capacidades.
