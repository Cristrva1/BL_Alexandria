# Cómo empezar sin instalar de más

La ficha indica si estás mirando una referencia, una skill, una librería, una aplicación o un servicio. Cada una entra de forma diferente en tu trabajo.

## Referencia o curso

Se lee primero. Elige un ejemplo y revisa sus requisitos. No copies todo un directorio de cursos a la carpeta de skills ni instales sus dependencias como un único producto.

## Skill o plugin

Instálalo mediante la ruta específica de tu agente. Una carpeta puede contener varias skills; copiar el repositorio completo no siempre registra ninguna. Reinicia o recarga el agente cuando la documentación lo indique y comprueba que aparece la instrucción o comando.

## Servidor MCP

Configura su comando local o URL en un cliente MCP. Prepara las credenciales y permisos de los servicios conectados. Comprueba que aparecen las herramientas. MCP no incluye un modelo ni una cuenta de IA.

## Librería

Añádela a un entorno o proyecto aislado con el gestor que documenta su autor. El nombre de un repositorio no siempre es el nombre del paquete. Los comandos de Alexandria se muestran solo cuando fueron seleccionados y encontrados en la fuente revisada.

## Aplicación, Docker o código fuente

Comprueba el sistema operativo, las dependencias, el almacenamiento y los servicios requeridos. Copiar o clonar descarga archivos; aún puede faltar instalar dependencias, configurar el entorno, obtener modelos, preparar una base de datos y arrancar el servicio.

## Antes de la primera ejecución

Elige una ruta de acceso al modelo, comprueba el plan y empieza con un ejemplo pequeño. Guarda las credenciales fuera del repositorio. Revisa el resultado y los costes observados antes de activar tareas largas o conectar datos reales.

## Si necesitas ayuda paso a paso

La ficha del explorador incluye un encargo para copiar a Claude Code, Codex o tu asistente. También puedes pedir: «Quiero usar [nombre del repo] para [mi objetivo]. Lee su README actual, pregunta mi sistema operativo, explica cuenta y costes, y guíame una acción a la vez hasta una primera prueba. Verifica cada resultado antes de continuar». La ayuda para instalar y el acceso al modelo de la aplicación son decisiones diferentes.

## Si aparece un error

Detente en ese paso y conserva el mensaje exacto, sin claves ni datos personales. Comprueba que la guía corresponde a tu versión y sistema. Pide ayuda con ese mensaje y el último paso completado; repetir todos los comandos o instalar más repos no suele aclarar la causa.
