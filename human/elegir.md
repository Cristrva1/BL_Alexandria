# Encuentra lo que necesitas

No necesitas conocer el nombre del repo. Elige un área de trabajo o una tarea y compara unas pocas opciones.

## Elige un área y una subcategoría

En Categorías encontrarás Frontend, Ciberseguridad, Producción audiovisual, Trading y otros campos. Entra en uno y elige una tarea concreta: por ejemplo Producción audiovisual → Voz: narración, síntesis y clonación. Verás sus repositorios y podrás filtrar por acceso y preparación.

## Prepara el asistente que ya utilizas

Las colecciones Configuración de Claude Code, Configuración de Codex y Configuración de Antigravity reúnen primeros pasos, skills y recursos compatibles. Empieza por el cliente oficial y añade una mejora cada vez. Consultar estas colecciones no significa que tu suscripción incluya las APIs de todas las aplicaciones que construyas.

## Un proyecto puede servir para varios temas

Un mismo repo puede ayudarte en desarrollo web y en la configuración de tu agente. Conserva una sola ficha, identidad y perfil de acceso. Por eso las cifras de las áreas pueden solaparse: no se suman para contar proyectos distintos.

## Empieza por una tarea

En Guíame puedes describir lo que quieres hacer o elegir una tarea del catálogo. Verás una primera opción que toma en cuenta tu equipo y acceso, y cuándo conviene considerar otras. Si ya estás explorando una subcategoría, abre «Ayúdame a elegir para esta tarea» para saltar a la recomendación.

## Para qué hay tantas herramientas

La biblioteca conserva opciones para distintos equipos, cuentas, licencias y formas de trabajar. Guíame usa la opción principal de la revisión editorial cuando encaja con tu perfil. Las alternativas explican qué necesidad puede cambiar la elección. En los grupos pendientes de curación, la puntuación de calidad sirve para desempatar entre opciones de encaje equivalente.

## Elige tu forma de acceso

Puedes buscar software que no necesita un modelo, herramientas para tu agente actual, aplicaciones con una API o modelos locales. Son filtros diferentes: una aplicación instalada en tu PC puede seguir llamando a un proveedor remoto.

## Abre dos o tres fichas

Lee qué hace, cuándo elegirlo, qué acceso requiere y cómo empezar. Compara alternativas para el mismo trabajo. Combina herramientas cuando cubran etapas diferentes de una receta.

## Haz una prueba pequeña

Empieza con un ejemplo del README original, tus datos de prueba y una ruta de acceso concreta. Un comando documentado significa que aparece en la fuente revisada; no que Alexandria haya ejecutado ese proyecto.

## Qué significan las etiquetas

Punto de partida es una selección editorial para empezar a comparar. Estrellas es popularidad en GitHub. Archivado indica que ese repositorio ya no recibe cambios. Por confirmar indica una pregunta que las fuentes revisadas no permiten resolver.
