# Encuentra lo que necesitas

No necesitas conocer el nombre del repo. Empieza por el resultado que buscas y compara unas pocas opciones.

## Describe el resultado

Piensa en una tarea concreta: transcribir un audio, preguntar a PDFs, atender WhatsApp o crear una presentación. Las rutas por objetivo te llevan a un conjunto pequeño y explican qué pieza cumple cada función.

## Elige tu forma de acceso

Puedes buscar software que no necesita un modelo, herramientas para tu agente actual, aplicaciones con una API o modelos locales. Son filtros diferentes: una aplicación instalada en tu PC puede seguir llamando a un proveedor remoto.

## Abre dos o tres fichas

Lee qué hace, cuándo elegirlo, qué acceso requiere y cómo empezar. Compara alternativas para el mismo trabajo. Combina herramientas cuando cubran etapas diferentes de una receta.

## Haz una prueba pequeña

Empieza con un ejemplo del README original, tus datos de prueba y una ruta de acceso concreta. Un comando documentado significa que aparece en la fuente revisada; no que Alexandria haya ejecutado ese proyecto.

## Qué significan las etiquetas

Punto de partida es una selección editorial para empezar a comparar. Estrellas es popularidad en GitHub. Archivado indica que ese repositorio ya no recibe cambios. Por confirmar indica una pregunta que las fuentes revisadas no permiten resolver.
