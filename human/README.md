## Cómo leer una ficha

Cada ficha empieza por el resultado y el acceso: API de IA, Claude Code, Codex, modelos locales, coste y equipo. Después incluye pasos de arranque, criterios de elección, alternativas y fuentes.

Un punto de partida es una selección editorial. Las estrellas indican popularidad. Un comando documentado no es una prueba de instalación. Una compatibilidad no documentada sigue siendo una pregunta abierta.
