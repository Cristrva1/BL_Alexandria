## Qué es

Skills listas para Claude Code, Codex y otros agentes que cubren pruebas, rendimiento, accesibilidad, revisión de código y buenas prácticas web. Pensadas para que el agente trabaje como un ingeniero senior.

## Por qué destaca

Autor con mucha experiencia en ingeniería web en Google; skills concretas y bien documentadas.

## Cómo funciona

Cada skill es una carpeta con SKILL.md e instrucciones que el agente carga cuando la tarea coincide.

## Instalación rápida

Copia las carpetas a `.claude/skills/` (o la carpeta de skills de tu agente) o instálalas como plugin.

## Casos de uso

- Auditar rendimiento web
- Revisiones de código más estrictas
- Mejorar accesibilidad de una app
