**Ejecución** 🏠 local · **Rol** 📚 librería/SDK · **Setup** 🟢 fácil

## Qué es

Añade clases como `btn` o `card` sobre Tailwind para escribir menos HTML, sin JavaScript.

## Por qué destaca

Rápida de adoptar y compatible con cualquier framework.

## Cómo funciona

Plugin de Tailwind que genera clases de componentes y temas con variables CSS.

## Instalación rápida

`npm i -D daisyui` y añádelo como plugin en tu CSS de Tailwind.

## Casos de uso

- Prototipos rápidos con Tailwind
- Temas claro y oscuro
- Proyectos sin React
