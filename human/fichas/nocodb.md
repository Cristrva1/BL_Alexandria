# 🧱 NocoDB

> Alternativa auto-hospedable a Airtable que convierte bases SQL en hojas de cálculo colaborativas.

**Ejecución** 🏠 local · **Rol** ⚙️ plataforma · **Setup** 🟢 fácil

## Qué es

Ofrece vistas de tabla, kanban, galería y formularios sobre PostgreSQL, MySQL o SQLite, con API REST automática. Útil como backoffice rápido para equipos no técnicos.

## Por qué destaca

Se conecta a bases existentes y genera API al instante; muy fácil de desplegar.

## Cómo funciona

Lee el esquema de tu base, lo presenta como hojas colaborativas y expone endpoints REST con tokens.

## Instalación rápida

`docker run -d -p 8080:8080 nocodb/nocodb:latest`.

## Casos de uso

- CRM ligero hecho a medida
- Backoffice sobre una base existente
- Formularios que guardan en SQL
