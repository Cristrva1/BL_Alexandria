## ¿Qué es?

D3 (Data-Driven Documents), librería JavaScript de bajo nivel para visualización de datos. Licencia ISC. Es infraestructura muy madura (~114k estrellas, v7.9.2).

## ¿Qué hace?

Une datos a elementos del DOM y ofrece módulos para escalas, ejes, formas, layouts (jerarquías, fuerzas, geografía), transiciones, interacción y carga de datos. No da gráficos prediseñados, sino primitivas para construir visualizaciones a medida con SVG, Canvas o HTML. Muchas librerías de alto nivel se apoyan en sus módulos.

## ¿Cómo lo hace?

Se instala con `npm install d3` (o módulos sueltos como `d3-scale`) o se carga como ES module desde un CDN. Es JavaScript puro sin dependencias y funciona en el navegador y en Node.
