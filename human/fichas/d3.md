# 📉 D3.js

> Librería JavaScript para visualizaciones de datos a medida con SVG, Canvas y HTML.

## Qué es

Da control total sobre cada elemento visual. Base de muchas librerías de gráficos y del periodismo de datos.

## Por qué destaca

Flexibilidad sin límites para visualizaciones únicas.

## Cómo funciona

Une datos a elementos del DOM y ofrece módulos de escalas, formas, layouts y transiciones.

## Instalación rápida

`npm i d3`.

## Casos de uso

- Visualizaciones interactivas únicas
- Mapas y grafos personalizados
- Gráficos para artículos
