# 🖥️ Marp

> Ecosistema para crear presentaciones con Markdown simple y exportarlas a PDF, PPTX o HTML.

**Ejecución** 🏠 local · **Rol** 🖥️ app · **Setup** 🟢 fácil

## Qué es

Escribes Markdown con separadores y obtienes slides limpias; tiene extensión de VS Code.

## Por qué destaca

Mínimo esfuerzo y exportación a PowerPoint.

## Cómo funciona

Marpit convierte Markdown en slides HTML con temas CSS; el CLI exporta a otros formatos.

## Instalación rápida

`npm i -g @marp-team/marp-cli` o la extensión Marp for VS Code.

## Casos de uso

- Slides rápidas desde notas
- Exportar a PowerPoint
- Presentaciones versionadas en Git
