## Qué es

Convierte un script de datos en una app web interactiva casi al instante.

## Por qué destaca

Muy popular en la comunidad de data science e IA por convertir un script en una app web interactiva casi al instante. Su modelo de rerun top-to-bottom simplifica la iteración frente a callbacks manuales.

## Cómo funciona

Ejecuta tu script de arriba abajo en cada interacción y mapea widgets y gráficos a una UI web reactiva servida automáticamente, con caché para evitar recálculos costosos.

## Instalación rápida

`pip install streamlit` y `streamlit run app.py`. Requiere Python; no necesita frontend aparte.

## Casos de uso

- Prototipo para consultar datos/resultados de un modelo
- Demos de datos y modelos para stakeholders
- Dashboards internos rápidos
