# 🖥️ k6

> Herramienta de pruebas de carga para medir cómo responden aplicaciones y servicios bajo distintos niveles de tráfico.

## ¿Qué es?

Herramienta de pruebas de carga y rendimiento de Grafana Labs. Licencia AGPL-3.0. Es muy madura y activa (~32k estrellas, v2.4.0).

## ¿Qué hace?

Ejecuta pruebas de carga escritas en JavaScript con el rendimiento de Go, sobre HTTP, WebSockets, gRPC, navegador y otros protocolos. Permite umbrales y checks para usarlas en CI, y tiene un amplio ecosistema de extensiones. Se integra de forma nativa con Grafana Cloud k6 y exporta resultados a distintos backends.

## ¿Cómo lo hace?

Es un binario en Go: se instala con gestores de paquetes, Docker o el binario oficial, y se ejecuta con `k6 run script.js`. Los scripts usan módulos ES; el módulo de navegador permite pruebas basadas en Chromium. Hay un servidor MCP oficial (grafana/mcp-k6, no catalogado) para agentes.
