## Cómo empezar

Se configura en tu agente. [Entender los términos](../vocabulario.md).

**Antes de empezar:**

- Un cliente admitido y, si consultas una tienda, una cuenta de desarrollo con alcance mínimo.

1. Sigue Install para el cliente elegido, revisa la opción de desactivar telemetría y empieza con documentación sin conectar tiendas reales.
2. Instala la integración para tu cliente en un proyecto de ejemplo y prueba una consulta de documentación.
3. Comprueba el resultado: el asistente enlaza la guía de Shopify o devuelve la estructura esperada para el ejemplo.

La primera prueba se propone; no se ejecutó el proyecto.
