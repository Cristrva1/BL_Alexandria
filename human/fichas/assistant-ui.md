## Qué es

Componentes componibles de chat con streaming, adjuntos, markdown y herramientas, compatibles con AI SDK y LangGraph.

## Por qué destaca

La experiencia de chat tipo ChatGPT más completa como librería.

## Cómo funciona

Primitivos headless y componentes estilados conectados a runtimes de distintos backends.

## Instalación rápida

`npx assistant-ui@latest init`.

## Casos de uso

- Chat de soporte en tu web
- Interfaz para un agente propio
- Prototipo de asistente
