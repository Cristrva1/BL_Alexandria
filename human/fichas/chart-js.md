## Qué puedes hacer con él

Librería JavaScript para dibujar gráficos en canvas dentro de una página o aplicación web. No utiliza un modelo de IA para generar los gráficos.

## Por qué destaca

Muy fácil de usar y con enorme adopción.

## Cómo funciona

Recibe datos y configuración para renderizar gráficos de líneas, barras, áreas y otros tipos.
