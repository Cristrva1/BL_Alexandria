# 📉 Chart.js

> Librería JavaScript sencilla para gráficos HTML5 en canvas.

**Ejecución** 🏠 local · **Rol** 📚 librería/SDK · **Setup** 🟢 fácil

## Qué es

Ocho tipos de gráfico listos, responsivos y animados con muy poco código. Ideal para dashboards web simples.

## Por qué destaca

Muy fácil de usar y con enorme adopción.

## Cómo funciona

Dibuja en un elemento canvas a partir de una configuración JSON.

## Instalación rápida

`npm i chart.js`.

## Casos de uso

- Gráficos en un panel admin
- Reportes web simples
- Prototipos de dashboards
