## Qué es

Analítica web completa con embudos, mapas de calor y comercio electrónico, auto-hospedada.

## Por qué destaca

La alternativa más completa y veterana a Google Analytics.

## Cómo funciona

Un tracker JavaScript envía datos a una app PHP con MySQL que procesa informes.

## Instalación rápida

Self-host con el paquete oficial o `docker run -p 8080:80 matomo`.

## Casos de uso

- Sustituir Google Analytics
- Analítica de e-commerce
- Cumplir normativas de datos
