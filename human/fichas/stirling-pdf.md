# 📑 Stirling-PDF

> Aplicación web auto-hospedada para editar, unir, dividir, convertir y firmar PDFs.

**Ejecución** 🏠 local · **Rol** 🖥️ app · **Setup** 🟢 fácil

## Qué es

Más de 50 herramientas de PDF en el navegador sin enviar archivos a terceros.

## Por qué destaca

La app de PDF open source más popular, completa y privada.

## Cómo funciona

Backend Java con librerías de PDF y una interfaz web.

## Instalación rápida

`docker run -d -p 8080:8080 stirlingtools/stirling-pdf`.

## Casos de uso

- Unir y dividir PDFs en la empresa
- Convertir Office a PDF
- Firmar y comprimir documentos
