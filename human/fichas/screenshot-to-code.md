## Qué es

Sube una imagen o graba un video de una web y obtén código funcional que puedes iterar.

## Por qué destaca

Muy popular y efectivo con los mejores modelos de visión.

## Cómo funciona

Envía la imagen a un modelo de visión con instrucciones de framework y muestra el resultado en vivo.

## Instalación rápida

Clona el repo y ejecuta backend (`poetry run uvicorn`) y frontend (`yarn dev`), o usa Docker.

## Casos de uso

- Clonar una landing a partir de captura
- Pasar mockups a código
- Prototipos rápidos
