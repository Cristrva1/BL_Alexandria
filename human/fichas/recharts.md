# 📉 Recharts

> Librería de gráficos para React construida con D3, declarativa y componible.

|---|---|---|---|---|

**Ejecución** 🏠 local · **Rol** 📚 librería/SDK · **Setup** 🟢 fácil

## Qué es

Construye gráficos con componentes de React. Muy usada en dashboards de apps React y en shadcn/ui.

## Por qué destaca

Encaja de forma natural en proyectos React.

## Cómo funciona

Componentes React que renderizan SVG usando utilidades de D3.

## Instalación rápida

`npm i recharts`.

## Casos de uso

- Gráficos en una app React
- Dashboards con shadcn/ui
- Reportes interactivos
