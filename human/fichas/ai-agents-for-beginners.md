## Qué es

Recorre desde qué es un agente hasta producción: frameworks, patrones de diseño (uso de herramientas, planificación, multiagente, metacognición), RAG agéntico, protocolos MCP, A2A y NLWeb, context engineering, memoria, agentes que usan el navegador, despliegue, agentes locales y seguridad. Cada lección trae README, video corto y ejemplos en Python.

## Por qué destaca

Es gratuito, está bien estructurado y tiene traducciones a más de 50 idiomas, español incluido. Cada lección es independiente, así que puedes empezar por la que te interese.

## Cómo funciona

Las lecciones son carpetas numeradas con su README y su carpeta `code_samples`; los ejemplos usan Microsoft Agent Framework y Microsoft Foundry Agent Service, y algunos admiten proveedores compatibles con OpenAI.

## Instalación rápida

Lee las lecciones en GitHub; para ejecutar el código, clona el repo (el README explica cómo omitir las traducciones) y sigue `00-course-setup`, que pide una cuenta de Azure con Microsoft Foundry.

## Casos de uso

- Aprender patrones de agentes con ejemplos en Python
- Formar en español a un equipo que empieza con agentes
- Entender MCP, A2A y memoria de agentes desde cero
