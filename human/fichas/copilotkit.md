## Qué es

Añade copilotos, chat y agentes que actúan sobre tu app, con estado compartido entre agente y UI. Se integra con LangGraph, Mastra y más.

## Por qué destaca

Conecta agentes del backend con la interfaz de forma estándar (AG-UI).

## Cómo funciona

Componentes React y un runtime que sincronizan estado, acciones y streaming entre la UI y el agente.

## Instalación rápida

`npx copilotkit@latest init` o `npm i @copilotkit/react-core @copilotkit/react-ui`.

## Casos de uso

- Copiloto dentro de un SaaS
- Agentes que editan formularios
- UI generativa con LangGraph
