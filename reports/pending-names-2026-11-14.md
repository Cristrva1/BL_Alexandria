## Acceso explicado en las fichas

- **Creative Architect:** plugin para Claude Code. Puede preparar briefs y prompts; generar medios requiere el proveedor conectado y sus créditos. Codex y generación local permanecen sin integración documentada. El README todavía dice privado, mientras que la API de GitHub marca el repositorio público al revisar; la ficha señala la discrepancia.
- **Cybersecurity Skills:** instrucciones para Claude Code, Codex CLI y otros clientes compatibles. El acceso al modelo corresponde al agente y cada skill puede necesitar herramientas propias. La ficha distingue biblioteca de instrucciones, herramienta de análisis y alcance autorizado.
- **Kimi K2.7 Code:** API de Moonshot o inferencia propia documentada. Disponer de pesos no garantiza poder ejecutarlos en un portátil ni que estén cubiertos por una suscripción de otro proveedor.

Se conservan las identidades numéricas y SHA de README de los dos proyectos de GitHub. Para el modelo se conserva el id de Hugging Face, la revisión inmutable y el hash del README. Las fuentes de cada ficha permiten revisar esas decisiones sin publicar el documento original.

Los dos nombres ambiguos necesitan una atribución que enlace el recurso original con su autor o repositorio. No se envió ningún comentario, mensaje ni solicitud a sus creadores.
